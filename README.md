# El Grimorio

Sistema web para la gestión y administración de una biblioteca, desarrollado como proyecto académico de Ingeniería de Sistemas. El proyecto integra gestión de libros, autores, categorías, editoriales, idiomas, lectores, usuarios y préstamos mediante una interfaz web moderna y organizada.

## Enfoque

El Grimorio está orientado a centralizar y facilitar la administración de los procesos principales de una biblioteca, integrando:

* Gestión de libros y catálogo bibliográfico
* Administración de autores, categorías, editoriales e idiomas
* Registro y gestión de lectores
* Gestión de usuarios y acceso al sistema
* Administración y seguimiento de préstamos
* Control de estados de libros y préstamos
* Dashboard administrativo con información general del sistema
* Gestión de perfil y credenciales de usuario
* Interfaz web adaptable y centrada en una experiencia de uso clara

## Tecnologías utilizadas

* Python
* Flask
* MySQL
* PyMySQL
* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* Font Awesome
* Iconify

## Arquitectura

El proyecto utiliza una estructura organizada por responsabilidades, separando los principales componentes de la aplicación:

* **Controllers:** gestión de las rutas y lógica de los módulos
* **Models:** interacción con la base de datos
* **Database:** configuración y estructura de la base de datos
* **Templates:** interfaces y vistas del sistema
* **Static:** archivos CSS, JavaScript e imágenes
* **Utils:** funciones auxiliares, validaciones y utilidades

## Módulos principales

El sistema cuenta con diferentes módulos para la administración de la biblioteca:

* 📚 Libros
* ✍️ Autores
* 🗂️ Categorías
* 🏢 Editoriales
* 🌐 Idiomas
* 👥 Lectores
* 👤 Usuarios
* 🔄 Préstamos
* 📊 Dashboard
* ⚙️ Perfil de usuario

## Base de datos

El sistema utiliza **MySQL** para almacenar y gestionar la información relacionada con los libros, usuarios, lectores, préstamos y demás entidades que conforman la biblioteca.

La estructura de la base de datos se encuentra incluida en el directorio `database/` para facilitar la configuración y puesta en marcha del proyecto.

## Objetivo

El proyecto busca aplicar conocimientos de desarrollo web, programación backend, gestión de bases de datos, arquitectura de aplicaciones y diseño de interfaces en la construcción de una solución funcional para la administración de una biblioteca.
